# 🧬 Protein Language Model for Enzyme Generation

## 🚀 Project Overview

This project implements a Transformer-based Large Language Model (LLM) to generate novel enzyme sequences using deep learning.

The model learns patterns from known enzyme sequences  and generates biologically valid protein sequences, demonstrating the application of Generative AI in protein engineering.

 🧠 Model Details

* Architecture: Transformer-based autoregressive model
* Input: Amino acid sequences
* Output: Generated protein sequences
* Loss Function: Cross-Entropy
* Optimizer: AdamW

---

 📊 Results

* Successfully generated enzyme-like protein sequences
* Training loss reduced from ~2.6 → ~1.3
* Generated sequences:

  contain valid amino acids
  follow realistic length distribution
  are not copied from training data

---

🔬 Validation

* Verified amino acid validity
* Checked sequence similarity (no memorization)
